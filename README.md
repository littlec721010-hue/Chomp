# what-should-we-eat

## Yuhan’s interactive HiFi

React Native + Expo + TypeScript. Run `pnpm install`, then `pnpm start` and scan the QR code with Expo Go. `pnpm web` opens the browser preview; `pnpm ios` / `pnpm android` require the corresponding simulator SDK.

Validation: `pnpm test`, `pnpm typecheck`, `pnpm build` (Web, iOS, and Android exports).

See [module scope and team integration](docs/yuhan-integration.md).
